# PSG-backend

This repository contains the backend of the Management System Project for ESEA SA.

## Overview

The backend is built with Java, Spring Boot, and Maven. It provides RESTful APIs and core business logic for the management system.

## Getting Started

1. Clone the repository.
2. Configure the database connection in `application.properties`.
3. Build the project with Maven:# PSG-backend
4. Run the application:

## Requirements

- Java 17+
- Maven 3.8+
- A relational database (e.g., MySQL, PostgreSQL)
